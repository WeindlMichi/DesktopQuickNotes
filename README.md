# DesktopQuickNotes

Ein leichtgewichtiges Windows-Desktop-Notizprogramm, entwickelt mit C# und WPF.

## 🚀 Features
* **Desktop-Fenster:** Öffnet ein schwarz-transparentes Fenster direkt auf dem Desktop.
* **Flexibel:** Größe lässt sich einfach verstellen und das Fenster unkompliziert schließen.
* **Auto-Save:** Speichert eingegebenen Text, Schriftgröße und Fensterposition automatisch in einer JSON-Datei.

## 🛠️ Starten
1. Repository klonen.
2. Projekt in **Visual Studio** öffnen.
3. Projekt kompilieren (Builden).
4. Kompilierte `.exe` ausführen.
